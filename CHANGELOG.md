# Changelog

Notes for the current version. Every earlier version is on [GitHub Releases](https://github.com/LeLibrary/LeLibrary/releases).

## [6.0.3]

### Fixes

- Watch history sync now copies the last 12 months of what you have already finished in Nuvio the first time you switch it on for Simkl, MDBList or AniList, instead of starting empty and only ever seeing new plays. After that first copy it carries on with what you finish. Setups that already had a sync switched on get that first copy once too, so MDBList users get their existing history across.
